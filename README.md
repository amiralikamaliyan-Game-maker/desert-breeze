# 🇮🇷 فارسی (Persian)

## 🐍 درباره بازی Desert Breeze

**Desert Breeze** یک بازی اسنیک پیشرفته است که توسط یک برنامه‌نویس ایرانی ساخته شده است. 🇮🇷

هدف این پروژه، گسترش تجربه‌ی بازی کلاسیک اسنیک و تبدیل آن به یک ماجراجویی سرگرم‌کننده‌تر است؛ تجربه‌ای که در آن بازیکن فقط به خوردن غذا و افزایش امتیاز محدود نمی‌شود، بلکه می‌تواند سکه جمع‌آوری کند، از فروشگاه بازی خرید کند، قدرت‌های ویژه به دست بیاورد و قابلیت‌ها و مراحل جدید را باز کند.

این پروژه با هدف به‌اشتراک‌گذاری یک بازی ساخته‌شده توسط توسعه‌دهنده‌ای ایرانی با جامعه‌ی جهانی برنامه‌نویسان و بازیکنان منتشر شده است.

**ساخته‌شده توسط یک برنامه‌نویس ایرانی، برای بازیکنان سراسر جهان.** 🇮🇷🌍

## ✨ امکانات بازی

- 🐍 **گیم‌پلی اسنیک:** تجربه‌ی بازی کلاسیک مار با امکانات توسعه‌یافته.
- 🪙 **سیستم سکه:** استفاده از سکه‌های داخل بازی برای خرید امکانات.
- 🛒 **فروشگاه داخلی:** خرید آیتم‌ها با استفاده از سکه‌های بازی.
- ⚡ **قدرت‌های ویژه:** امکان خرید قدرت‌ها و آیتم‌های ویژه‌ی موجود در فروشگاه.
- 🔓 **قابلیت‌های قابل بازکردن:** بازکردن امکانات و مراحل بیشتر.
- 🎮 **سیستم پیشرفت:** انگیزه برای ادامه‌ی بازی، جمع‌آوری سکه و کشف محتوای بیشتر.

۴. وارد فروشگاه شوید.

۷. بازی کنید، مهارت خود را بهتر کنید و از تجربه‌ی اسنیک لذت ببرید!

## 💻 نصب و اجرای بازی

ابتدا مطمئن شوید Python روی سیستم شما نصب شده است.

```bash
python --version
```

مخزن پروژه را دریافت کنید:

```bash
git clone https://github.com/amiralikamaliyan-Game-maker/desert-breeze.git
```

وارد پوشه‌ی پروژه شوید:

```bash
cd desert-breeze
```

اگر فایل `requirements.txt` در پروژه وجود دارد، وابستگی‌ها را نصب کنید:

```bash
python -m pip install -r requirements.txt
```

بازی را اجرا کنید:

```bash
python main.py
```
